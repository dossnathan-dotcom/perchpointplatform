# Source Precedence

1. Explicitly approved customization decisions in the execution directive.
2. Most recent approved master roadmap.
3. Platform vision.
4. Direct stakeholder statements in discovery.
5. Accepted Phase 0 contracts and verification evidence.
6. Existing application behavior.
7. Agent inference or recommendation.

Lower sources may add detail but cannot reverse higher authority. Every conflict records exact
claims and references, consequence, safe assumption, decision owner, whether work can continue,
and status in `docs/source/provenance/SOURCE_CONFLICT_REGISTER.md`.

Labels used throughout: fact, approved decision, assumption, recommendation, unresolved
question, existing behavior, and aspiration.
