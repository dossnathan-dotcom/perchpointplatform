# Canonical Terminology

- **PerchPoint:** HawkVision's property operating system.
- **HawkVision Homes:** client/operator; exact legal entity is open.
- **Organization / ownership entity / property / building / unit / commercial space:** distinct
  hierarchy and jurisdictional scopes; commercial and mixed-use records are first-class.
- **Person:** individually identified human. **Household:** relationship container, not a shared login.
- **Applicant / co-applicant / guarantor / occupant / business party / authorized representative:**
  distinct roles with attributable access and decisions.
- **Provider record:** external processor state. **Operational fact:** PerchPoint domain record.
  **Formal accounting fact:** accounting system record.
- **Recommendation:** preserved technician advice. **Override:** attributable selection of a
  materially different remedy; never overwrites the recommendation.
- **Delegation:** scoped, bounded, expiring, revocable authority; never a shared master code.
- **Critical / decision required / action required / informational:** notification levels.
- **Phase:** controlled delivery/evidence gate. Do not use “MVP” to diminish final scope.
- Canonical sponsor spelling is **Faruk**. Source quotations may retain alternate spellings.
