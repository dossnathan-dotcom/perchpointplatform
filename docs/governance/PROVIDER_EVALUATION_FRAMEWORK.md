# Provider Evaluation Framework

Score each candidate 0–5 with documented evidence. Weighted categories: functional/API/webhook/
idempotency/sandbox 25%; security/compliance/data minimization 20%; reliability/support 15%;
total recurring/usage/transaction/contract cost 15%; exportability/lock-in/replacement 10%;
implementation/operations 10%; UX/accessibility 5%. Any legal/security/required-capability
failure is disqualifying regardless of score.

Record assumptions, rate limits, cancellation, migration, fallback, account ownership, and
switching cost. Phase 0/1 authorizes evaluation only, not purchase or production activation.
