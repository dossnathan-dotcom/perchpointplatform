# Change Control

Every change identifies requirements, owner, risk, tests/evidence, migration/configuration,
security/permission impact, rollback, limitations, and acceptance authority. Generated contracts
freeze before parallel implementation. Emergency changes are narrowly scoped, attributable,
time-bounded, reviewed afterward, and never expand business authority silently.

Commits, pushes, PRs, merges, deployments, provider activation, and phase advancement require
their explicit authority. GitHub is canonical.
