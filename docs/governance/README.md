# Phase 1 Governance

This directory is the operational index for PerchPoint governance. Normative requirements live
in `REQUIREMENTS_TRACEABILITY.md`; product identity lives under `docs/product`; source
provenance lives under `docs/source`; independent evidence lives in
`docs/audits/PHASE_0_CURSOR_AUDIT.md`.

- `APPROVED_DECISION_REGISTER.md` maps every material approved decision to requirements,
  policy, ownership, verification, and acceptance.
- `PLATFORM_VISION_TRACEABILITY.md` maps authoritative PDF page detail to existing atomic
  requirements without duplicating them.
- `NORMATIVE_COVERAGE.md` classifies each governance artifact and maps its normative content.
- `PHASE_1_ACCEPTANCE.md` records current evidence and blockers.

Acceptance is provisional wherever a named business or specialist decision remains open.
