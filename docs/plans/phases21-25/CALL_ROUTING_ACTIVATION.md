# Call routing activation

No real number, port, carrier change, or provider account is part of this bundle.

## What is local

- Ann-first simulated routing during the America/New_York business calendar.
- A keypad digit 9 emergency branch and the existing human-acceptance chain.
- Manual records when the call never entered a provider route.
- Signature checks on synthetic webhook fixtures.
- A routing graph that refuses a forwarding loop.

## What stays later

Number ownership, the receiving device, whether a carrier can forward events,
porting, SMS implications, destination fallback, and recording consent.
Verifying outbound caller ID does not make inbound mobile calls observable.
Forwarding into a provider and back to the same destination can loop, so the
graph is rejected instead of activated.

A `tel:` link does not prove that a call connected or how long it lasted.
Carrier voicemail does not count as a person accepting the handoff.
No recording, transcription, or media stream can be enabled by a setting.
