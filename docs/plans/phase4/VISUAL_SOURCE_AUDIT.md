# Emergent visual-source audit

The public site and the eight role shells in this repository are the Emergent visual source. Phase 4 does not replace them with a generic dashboard.

| Element | Classification |
|---|---|
| Public hero, listings, about, footer, copper/obsidian/linen/gold palette | Preserve and refine into tokens |
| Role shell sidebar, workspace labels, Phase 0 slugs | Preserve |
| Phase 2 reference kernel | Preserve |
| Google Fonts and the Emergent/PostHog scripts | Remove |
| Raw `#090d12` portal background | Refine to the obsidian token |
| Duplicate preview queues that imply a finished workflow | Refine copy so actions stay unavailable |
| Canonical search, document processing, approvals | Defer |

Future visual refinement, if any, belongs on `emergent/phase-04-slice` after these tokens, routes, and component APIs. Phase 4 does not wait on another Emergent session.
