# Phase 4 scope

In scope: tokens, themes, density, shared components, a local component laboratory, role navigation, honest synthetic states, security headers, a no-op analytics boundary, and public-form abuse controls.

Out of scope: canonical search, document processing, production identity, applications, screening, leases, payments, maintenance workflows, communications providers, and the approval engine.

Existing Phase 2 reference routes and the Phase 3 container gates stay in force.
