`APPROVED_CUSTOMIZATION_ANSWERS.md`. “Named test” means the repository contains the referenced
test; it does **not** mean this documentation change executed it. `UNVERIFIED` means implementation
or a test was observed but no current-commit evidence was produced here. `PLACEHOLDER` means the

always `BLOCKED_EXTERNAL`.
